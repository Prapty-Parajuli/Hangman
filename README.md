# Hangman Game
## Description
This is a simple terminal-based hangman game in Python. The word is picked by the computer and the player has to guess it letter by letter. 
Features:
- Word Filtering
- Visual hangman stages
- Tracking of correct and incorrect guesses
## Requirements
- Python 3.x
- nltk library
- Before running the game, open a random python script and run the folloowing to install dataset
```python
import nltk
nltk.download('words')
```
## How to run
```bash
python hangman.py
```
